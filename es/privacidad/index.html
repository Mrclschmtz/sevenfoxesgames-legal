2. Lo más importante primero

Este sitio web no utiliza cookies y no te sigue a través de otros sitios web. Las fuentes se cargan desde nuestro propio espacio web, no desde Google. Durante tu visita solo se tratan datos personales en dos lugares: en los registros del servidor de nuestro proveedor de alojamiento (apartado 3) y, de forma breve, en nuestro recuento de visitas respetuoso con la privacidad (apartado 4).

3. Alojamiento (GitHub Pages)

El sitio web se sirve a través de GitHub Pages, un servicio de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, EE. UU. Al abrir una página, GitHub trata datos de conexión técnicamente necesarios: dirección IP, fecha y hora, página solicitada, volumen de datos transferido, navegador y sistema operativo, y la página de procedencia (referrer). GitHub conserva estos datos en registros del servidor para garantizar la seguridad y la estabilidad del servicio.

La base jurídica es nuestro interés legítimo en ofrecer el sitio web de forma segura y eficiente (art. 6, apdo. 1, letra f del RGPD). Los datos se transfieren a EE. UU.; GitHub está certificada conforme al EU-US Data Privacy Framework. Nosotros no tenemos acceso a esos registros. Más información: declaración de privacidad de GitHub.

4. Recuento de visitas (GoatCounter)

Para saber cuántas personas visitan nuestras páginas y cómo nos encuentran, utilizamos GoatCounter, un servicio de Martin Tournoij (Irlanda). Al abrir una página, tu navegador carga un pequeño script desde gc.zgo.at y envía un recuento a sevenfoxes.goatcounter.com. Se transmiten la página visitada, la página anterior (referrer), el navegador y el sistema operativo, el idioma, el tamaño de pantalla y tu dirección IP; la dirección IP solo se utiliza para determinar el país (y, en las visitas desde EE. UU., Rusia y China, también la región). El tamaño de pantalla y el idioma no se almacenan.

GoatCounter no almacena direcciones IP, no utiliza cookies y no asigna identificadores permanentes. Para no contar dos veces las visitas repetidas, se genera un identificador de sesión aleatorio a partir del nombre del sitio, la dirección IP y la identificación del navegador; permanece como máximo ocho horas en memoria y no se almacena. Solo se guardan estadísticas agregadas (por ejemplo, «12 visitas desde Alemania el 6 de octubre»), que no permiten identificar a ninguna persona. Los servidores están en Hetzner Online GmbH, en Alemania y Finlandia.

La base jurídica es nuestro interés legítimo en medir y mejorar el alcance de nuestro sitio web (art. 6, apdo. 1, letra f del RGPD). Puedes oponerte al recuento en cualquier momento (art. 21 del RGPD); lo más sencillo es bloquear los scripts de gc.zgo.at y goatcounter.com en tu navegador o con un bloqueador de contenido. Más información: política de privacidad de GoatCounter.

5. Contacto por correo electrónico

Si nos escribes, tratamos tu dirección y el contenido del mensaje para responder a tu solicitud (art. 6, apdo. 1, letras b o f del RGPD). Nuestro buzón está alojado en netcup GmbH, Daimlerstraße 25, 90441 Núremberg, Alemania. Eliminamos la correspondencia cuando el asunto queda resuelto y no existen obligaciones legales de conservación.

6. Enlaces externos

Este sitio enlaza al App Store de Apple y a la información de privacidad de Google. Al seguir uno de esos enlaces se aplica la política de privacidad del proveedor correspondiente. La mera visualización de nuestras páginas no transmite datos a esos proveedores.

7. Tus derechos

Tienes derecho de acceso (art. 15 RGPD), rectificación (art. 16), supresión (art. 17), limitación del tratamiento (art. 18), portabilidad (art. 20) y oposición (art. 21). También puedes presentar una reclamación ante una autoridad de control de protección de datos (art. 77 RGPD). Basta con un correo a kontakt@sevenfoxes.de.

8. Cambios

Actualizaremos esta política cuando el sitio web o los requisitos legales cambien. La versión vigente está siempre disponible en esta dirección.
