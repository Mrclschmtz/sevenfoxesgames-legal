So geht’s

  1. Lade Quizerra kostenlos im App Store und melde dich bei Game Center an.
  2. Tippe hier auf „Duell öffnen“ – oder öffne in der App „Duell“ → „Freund herausfordern“ → „Einladungscode eingeben“.
  3. Gib den Code ein, falls er nicht schon drinsteht. Schon bist du im selben Duell.

Der Link enthält nur den Code, keine persönlichen Daten. Das Duell läuft über Apples Game Center.
