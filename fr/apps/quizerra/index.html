Comment jouer

Deux minutes, concentration maximale

  1. Choisissez une catégorie – ou le mode Mixte, qui puise dans toutes les catégories.
  2. Répondez à autant de questions que possible en deux minutes. Après chaque réponse, on enchaîne aussitôt.
  3. Plusieurs bonnes réponses d’affilée construisent une série avec des points bonus.
  4. Dans le récapitulatif de la manche, revoyez toutes les questions avec la bonne réponse.
