Comment ça marche

  1. Téléchargez Quizerra gratuitement dans l’App Store et connectez-vous à Game Center.
  2. Touchez ici « Ouvrir le duel » – ou, dans l’app (qui s’affiche en anglais), ouvrez “Duel” → “Challenge a friend” → “Enter invite code”.
  3. Saisissez le code s’il n’est pas déjà rempli. Et voilà, vous êtes dans le même duel.

Le lien ne contient que le code, aucune donnée personnelle. Le duel passe par le Game Center d’Apple.
