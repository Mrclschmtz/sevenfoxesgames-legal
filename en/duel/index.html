How it works

  1. Download Quizerra for free from the App Store and sign in to Game Center.
  2. Tap “Open duel” here – or in the app, go to “Duel” → “Challenge a friend” → “Enter invite code”.
  3. Enter the code if it isn’t filled in already. That’s it – you’re in the same duel.

The link only contains the code, no personal data. The duel runs on Apple’s Game Center.
